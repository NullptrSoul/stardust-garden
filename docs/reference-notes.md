# 参考笔记：土豆兄弟和同类游戏

2026-11-06 整理。目的是学它们做得好的地方，再按我们的题材和手机竖屏改进，**不照搬任何素材、角色、名字和具体数值**。

## 看到了什么

**场地**（看的是 Steam 商店页截图）
- 地面没有格子，只有一种底色，加上满地零散的小碎石、骨头、枯叶。看起来有质感，又不抢眼。
- 场地比屏幕大，镜头跟着角色走，走到边上才能看到不规则的边缘。
- 怪物都是同一个色系（紫灰色），靠形状区分；玩家和掉落物用对比色，一眼能找到。

**界面**
- 左上角是红色血条、经验条和材料数，正上方是波次和倒计时，没有别的东西。
- 右上角会排出「待升级」的小图标，告诉你这波结束能升几级。
- 商店里每个商品下面有锁，锁住的东西刷新时不会被换掉，到下一波也还在；武器可以回收换钱；属性面板分主属性和次属性两页。

**怪物和机制**（来源见文末）
- 远程怪离你太近会跑开，同时向你射击。
- 有专门给其他怪回血的怪。
- 「掠夺者」类怪会逃跑，打死了掉宝箱和一大堆材料。
- 有周期性冲锋的怪。
- 场上有中立的树，打掉会掉回血果子或宝箱，每波血量会涨。

## 我们怎么做（改进点）

| 方面 | 它们的做法 | 我们的做法 |
|---|---|---|
| 场地 | 灰褐色荒地、碎石 | 漂浮在云上的星光花园小岛：柔和的草地、花瓣、小花、石子，边缘是带草皮的崖边，外面是会飘动的云海。题材和角色一致，不再是方格地砖 |
| 镜头 | 跟随 | 跟随，竖屏场地做成比屏幕宽一些、高一些 |
| 界面 | 电脑上信息很密 | 手机竖屏：左上角放角色头像，旁边是血条和经验条；中间是波次和倒计时；右上是暂停。字更大、按钮更大 |
| 属性 | 商店里常驻属性面板 | 手机屏幕小，做成随时能打开的属性页（暂停里、商店里都能看） |
| 商店 | 锁定、刷新、回收 | 一样有锁定和卖武器，另外用广告免费刷新一次 |
| 升级卡 | 只写加多少 | 同时写出「当前多少」，方便判断 |
| 怪物 | 冲锋、远程、治疗、逃跑、分裂 | 冲锋兔（先蓄力、地上画出冲锋路线再冲）、双子史莱姆（打死分成两只小的）、小偷猫（会跑，打死掉宝箱和一大把星屑，十几秒后逃走）、星光花苞（中立，打碎掉回血糖果） |
| 回血 | 果子 | 糖果：怪物偶尔掉，花苞必掉，捡到回 3 点生命 |
| 宝箱 | 波次结束开 | 波次结束开宝箱，得到一个道具，可以收下或卖掉换星屑 |

## 打击感（第二轮试玩反馈：打击感偏轻、画面太亮、地图偏小）

**资料里的共识**
- 打击感不是靠一招，而是命中那一瞬间（约 0.1 秒内）同时叠 5 到 8 个小反馈：顿帧、闪白、击退、粒子、音效、伤害数字、镜头轻推。只做好其中三样（顿帧 + 闪白 + 击退），也比七样都做一半强。
- 顿帧要让所有东西一起停，只停被打的怪会像「卡了一下」。轻击停 2 到 3 帧，重击才停更久。
- 击退要和伤害成正比。怪物被打了却纹丝不动，会让人觉得「打不动」。
- 屏幕震动要克制：每一下都震，玩三分钟就麻木了。只给暴击、击杀精英、受伤、大招这类重要时刻。
- 伤害数字可以合并，避免满屏数字。
- 要给玩家「关闭震动 / 闪光」的选项。
- 中文资料把命中那一帧称为「命中帧」，是放音效、光效、震屏、顿帧的窗口；越难打出的攻击，反馈应该越大。

**我们的改法**
- 顿帧：普通击杀停约 2 帧（有间隔限制，不会连成卡顿），暴击停 2 帧，击杀精英 / Boss、受伤、大招落地停 4 到 8 帧。
- 每次命中：闪白 + 怪物抖一下 + 往被打的方向溅出它颜色的果冻水滴 + 更厚实的「噗」声（白噪音 + 低频）。
- 击杀：先鼓一下再爆开，溅出更多水滴，地上留下几秒后淡去的果冻渍。
- 武器开火：枪口闪光；重武器开火时镜头往反方向轻推一下。
- 震动只给：暴击（小）、精英 / Boss、受伤、大招。
- 受伤时屏幕四周闪红；血量低于 30% 时四周持续淡红呼吸。
- 画面：草地和天空压暗、提高饱和度，四周加暗角，让中间的战斗更突出；顶部状态栏不再用白色渐变。
- 地图：场地放大约 1.8 倍（1500 × 2200），怪物在角色周围 200 到 650 的范围里刷，保证打得起来；多加几处花坛和石砌遗迹，大地图不单调。

## 以后可以再学的

- 武器流派加成：带同一流派的武器越多，额外加成越多，让「凑一套」有目标。
- 难度等级：通关后解锁更高难度。
- 「收获」属性：每波结束固定拿一些星屑，鼓励经济流打法。
