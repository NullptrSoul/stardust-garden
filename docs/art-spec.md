## chibi.png（战斗小人）

- 二次元 Q 版，大约 2 到 2.5 头身，**全身**。
- **透明背景**的 PNG。
- 站姿，**面朝右边**或右前方 3/4 侧面（向左走时游戏会自动镜像）。
- 高度 600 到 800 像素，脚踩在图片底边，四周只留很少空白。
- 不用画影子，游戏会自己画。
- 手里不拿武器：游戏里武器是浮在角色周围的图标。

## portrait.png（全身立绘，可选）

- 和参考图上排一样的全身立绘，透明背景，高度 1600 到 2000 像素。

## 必须去掉的东西

你的参考图是按 AI 产品拟人画的，正式素材里**不能出现**：

- 任何公司或产品的名字、文字
- logo，以及 logo 形状的道具，比如 logo 形状的棒棒糖、带 logo 的抱枕、徽章、图案
- 一眼就能认出是某家公司标志的元素

角色的发色、服装、配饰（龙角、猫耳、女仆装等）可以保留，这些不是商标。

## 保持风格统一

- 6 个角色用**同一个 AI 工具、同一个模型、同一套风格描述**生成。
- 先定下一个满意的角色，再用它当参考图生成其他角色。
- 线条细、上色柔和、淡紫粉嫩色调，和游戏里的场景、怪物统一。

## 分层小人（骨骼动画，类 Live2D）

有了分层图，战斗小人会呼吸、眨眼，侧发、裙摆、尾巴会摆，跑起来身体前倾、手臂轻摆。没有分层图的角色继续用 `chibi.png`，不会出错。

现状（2026-11-07）：**6 个角色都换成了分层小人**（muse 生成，深汐另用脚本修补）。白澜这张生成得比较修长（约 3 头身、及地长裙），裙下的腿是补出来的，所以她只呼吸、眨眼、摆头发和手臂，不前倾、不摆裙子和腿；以后可以让 muse 重画成 Q 版再拆。分开的两条腿跑步时会交替摆动。

### 流程

1. 分层 PNG 放进 `art-source/rig/<角色编号>/`（不进版本库）。
2. 运行：

   ```bash
   node tools/bake-rig.mjs shenxi
   ```

   脚本会把各层缩小、拼成一张图 `public/characters/<编号>/rig.png`，生成关节数据 `src/game/art/rigs/<编号>.ts`，并用同一套图层重新导出 `chibi.png`、`portrait.png`、`avatar.png`，保证各处形象一致。
3. 关节位置、修补规则写在 `tools/rig-config.json`。加 `--debug <目录>` 会输出一张标好关节的检查图。

`tools/extract-characters.mjs`（从参考图裁图）会自动跳过已经有分层图的角色。

### 最重要的规则

1. **所有图层画布一样大、位置对齐**：同一个画布上拆，每层导出成和画布同尺寸的透明 PNG，叠起来能原样拼回完整角色。
2. **每个物体完整地只在自己那一层**：整条尾巴只在 `tail.png`，手只在手臂层；`hair_back` 里只有头发，不能有衣服、头饰的副本。深汐的尾巴被分进了裙子、腿、身体三层，一摆就断开，只能靠脚本补救。
3. **图层边界沿着画出来的轮廓线走，不要用矩形框切**。矩形切口一动就是一条直线裂缝。
4. **被挡住的部分要补全**，用相邻的同色、同纹理平滑延伸，不要几何色块。图层会动，不补就会露洞。
5. **关节处多画一点**：手臂、头、腿和身体相接处各多延伸 10～20 像素，压在别的层下面。

### 出图姿势

- 正面或面朝右的 3/4 侧面，向左走时游戏会自动镜像。
- Q 版 2～2.5 头身，全身，脚踩在画布底部附近。
- A 字站姿：两只手臂稍微离开身体，头发不要盖住手臂。
- **手里不拿武器**：游戏里武器是浮在角色周围的图标。
- 尾巴整条露在身体后方。
- 透明背景，画布 1024×1280。

### 文件和分层

放在 `art-source/rig/<角色编号>/` 下，文件名照抄：

| 文件 | 内容 | 必须 |
|---|---|---|
| `hair_back.png` | 脑后垂下来的长发 | 必须 |
| `body.png` | 躯干和衣服（不含头、手臂、腿、会飘的裙摆） | 必须 |
| `head.png` | 脸、脖子、耳朵（不含眼睛、刘海）；眼眶处补成皮肤 | 必须 |
| `eyes_open.png` | 睁开的眼睛 | 必须 |
| `hair_front.png` | 刘海和脸两边的前发 | 必须 |
| `arm_back.png` / `arm_front.png` | 后面 / 前面那只手臂 | 必须 |
| `legs.png` | 两条腿和鞋（或拆成 `leg_back.png` + `leg_front.png`） | 必须 |
| `eyes_closed.png` | 闭眼；不给的话脚本用睁眼的位置自动画（配置 `eyesClosed: "generate"`） | 可选 |
| `skirt.png` | 会飘的裙摆或下摆 | 可选 |
| `hair_side_l.png` / `hair_side_r.png` | 两侧的鬓发、双马尾、长侧发 | 可选 |
| `tail.png` | 尾巴（紫铃的猫尾、深汐的鲸鱼尾） | 可选 |
| `ears.png` | 猫耳、龙角 | 可选 |
| `accessory.png` | 帽子、头顶发饰、蝴蝶结 | 可选 |
| `mouth_open.png` | 张开的嘴（受伤时换上） | 可选 |

默认叠放顺序（从下到上）：尾巴 → 后发 → 后腿 → 后臂 → 腿 / 前腿 → 身体 → 裙摆 → 头 → 眼睛 → 嘴 → 侧发 → 刘海 → 耳朵 → 发饰 → 前臂。顺序不同时在配置里写 `order`。

### 分层不干净时的补救（`tools/rig-config.json`）

- `split`：把某层框内（矩形或多边形）的像素交给另一根骨头带着动，例如把误分进裙子层的尾巴交给尾巴。被拆出的一块留在原来的叠放位置，所以静止画面不变。
- `follow`：整层跟着另一根骨头，例如深汐的后发边缘太乱，就让它跟身体一起动，不单独摆。
- `motion`：把某个动作调弱或关掉（呼吸、前倾、头、头发、侧发、尾巴、裙摆、手臂、腿）。
- `joints`：手动指定关节位置（脚、胯、脖子、头顶、腿根、裙腰、两肩、两侧发根、尾根）。

动作幅度都故意很小：图层是从一张图里拆出来的，被挡住的部分是补出来的，转得太多就会露馅。

### 用 AI 怎么做

现在用 muse 生成：先出一张满意的全身 Q 版图（3/4 朝右、A 字站姿、无 logo），再让它按上面的规则拆层、补全，打包成 `<编号>_rig_v1.zip`。拿到后检查：

1. 叠起来和原图一致；
2. 每层单独看，有没有别的部件的碎片、矩形切口；
3. 跑一遍 `bake-rig.mjs --debug`，在游戏里看动起来有没有裂缝。

也可以自己用 Photoshop / Photopea 拆：套索分层，用生成式填充补被挡住的部分，「文件 → 导出图层」。
