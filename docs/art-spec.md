# 角色图片出图要求

游戏会自动读取下面这些图片。图片放好后刷新网页，占位小人就会换成你的图。没有图的角色继续用占位小人，不会出错。

## 现在用的是临时素材

现在游戏里的角色图都是从你的两张参考图里**直接裁出来的**，原图在 `art-source/`（已经排除在版本库外），用下面的命令重新生成：

```bash
node tools/extract-characters.mjs
```

## chibi.png（战斗小人）

- 二次元 Q 版，大约 2 到 2.5 头身，**全身**。
- **透明背景**的 PNG。
- 站姿，**面朝右边**或右前方 3/4 侧面（向左走时游戏会自动镜像）。
- 高度 600 到 800 像素，脚踩在图片底边，四周只留很少空白。
- 不用画影子，游戏会自己画。
- 拿着自己的武器，但不要太长，不然站在一起会显得乱。

## portrait.png（全身立绘，可选）

- 和参考图上排一样的全身立绘，透明背景，高度 1600 到 2000 像素。

## 必须去掉的东西

你的参考图是按 AI 产品拟人画的，正式素材里**不能出现**：

- 任何公司或产品的名字、文字
- logo，以及 logo 形状的道具，比如 logo 形状的棒棒糖、带 logo 的抱枕、徽章、图案
- 一眼就能认出是某家公司标志的元素

角色的发色、服装、配饰（龙角、猫耳、女仆装等）可以保留，这些不是商标。

## 保持风格统一

- 6 个角色用**同一个 AI 工具、同一个模型、同一套风格描述**生成。
- 先定下一个满意的角色，再用它当参考图生成其他角色。
- 线条细、上色柔和、淡紫粉嫩色调，和游戏里的场景、怪物统一。

## 提示词参考

通用部分（每个角色都加上）：

```
二次元 Q 版少女，chibi，2 头身，全身，站立，面朝右侧，纯白背景，柔和赛璐璐上色，细线条，淡紫色调，精致，大眼睛闪亮，无文字，无 logo
```

```
chibi anime girl, full body, standing, 3/4 view facing right, plain white background, soft cel shading, thin lineart, pastel lavender palette, highly detailed, big sparkling eyes, no text, no logo
```

再加上表格里每个角色的形象要点。比如白澜：

```
white long hair, small white dragon horns, white flowing dress with lavender ribbons, purple eyes, white flower hairpin, holding a small star-tipped staff
```

如果工具不能直接出透明背景，就在纯白背景上生成，再用抠图工具去掉背景，注意头发边缘要干净。

## 版权提醒

- 确认你用的 AI 工具允许**商用**生成的图片。
- 保留每张图的生成记录（提示词、日期、截图），以后微信审核或申请软件著作权时，可能需要证明素材是原创。
