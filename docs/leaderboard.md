# 无尽排行榜：怎么开通

游戏里排行榜已经做好了（主界面「无尽模式」右边的「排行」按钮）。还没接数据库时，它只显示这台设备上的成绩；接上以后，所有人的成绩都在一个榜上。

## 方案

- **托管数据库**（下面两个二选一）：不用自己维护，也不用在自己服务器上开端口。
- **自己的服务器**：按 [leaderboard-server.md](leaderboard-server.md) 的接口跑一个小服务，配置里写 `kind: 'simple'` 和地址。需要正式域名和 HTTPS。
- 2026-11-07 问过 muse：它只有工作沙盒，没有长期在线的公网服务器，不能托管。

## 选一个数据库（二选一）

| | 腾讯云「云开发 CloudBase for Supabase 版」 | supabase.com |
|---|---|---|
| 国内访问 | 快，服务器在国内 | 没查到国内是否稳定，可能慢或连不上 |
| 注册 | 腾讯云账号，需要实名认证 | GitHub 账号直接登录 |
| 价格 | 新用户免费体验 6 个月（以官网为准） | 免费版够用（小项目一周不活跃会暂停，打开控制台恢复） |

玩家大多在国内，推荐腾讯云。两个用的是同一套接口，游戏代码不用改，换的话只改两行配置。

## 开通步骤

1. 注册并新建一个项目（数据库）。
2. 打开项目的 **SQL Editor**，把 [leaderboard.sql](leaderboard.sql) 整段粘进去，点运行。它会建好成绩表、两个榜（总榜、本周）和防作弊检查。重复运行也没关系。
3. 在项目的 **API 设置**（Settings → API）里找到两样东西：
   - **Project URL**（项目地址），像 `https://xxxx.supabase.co`
   - **anon public key** 或 **publishable key**（公开密钥）
4. 把这两样发给我，我填进 `src/leaderboard.config.ts`，测一遍再发布。

这两样本来就是公开的，放进网页里别人也能看到，没关系：数据库只允许游客「加一条合理的成绩」和「看榜」，不能改、不能删、也看不到原始表。**千万不要发 service_role key / secret key**，那个是管理员密钥。

## 规则

- 无尽模式一局真正结束时（死了且不再复活，或死后选了回主界面）自动上传，至少打到第 2 波。
- 第一次上传前要起个名字（最多 10 个字），排行榜页面下面可以改名，改了从下一局起生效。
- 每人只算最好的一局：先比波数，同波数比击败数。
- 总榜不清零；本周榜从北京时间周一 0 点算起。
- 结束界面显示这局在总榜和本周榜的名次（只和别人比，自己以前的成绩不算在前面）。

## 防作弊（基础）

数据库拒收不合理的成绩：

- 波数 2～200，击败数不超过波数 × 400，用时不超过 2 小时；
- **用时不能少于打到这一波的最短时间**（前面每个普通波都有固定时长，Boss 波算 0，再留 10% 余量）。这个公式在 `leaderboard.sql` 的 `min_play_time`，和游戏里的波次时长有测试保证一致；改波次时长要一起改。

这挡不住会改代码的人伪造「合理」的成绩。真要防，得录下每局的操作在服务器上重放，工作量很大，等微信版再考虑。发现刷榜可以在数据库控制台里直接删那几行。
