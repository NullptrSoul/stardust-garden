# 《星屑庭院》玩法设计（暂定名）

> 竖屏动作肉鸽：操控二次元少女在庭院里走位，武器自动攻击一波波萌系怪物；怪物掉落的星屑既是经验也是钱，波次之间升级选属性、逛商店买武器和道具，撑过 10 波，打倒史莱姆女王。

版本：v0.3（2026-11-06）｜状态：可玩原型，等试玩调数值

---

## 1. 设计目标

| 目标 | 具体要求 |
|---|---|
| 玩法 | 参考土豆兄弟这一类「竞技场生存 + 波次商店」玩法；角色、武器、道具、怪物、数值、美术都是原创 |
| 一局 | 10 波，约 8 分钟 |
| 操作 | 竖屏单手：手指在屏幕任意位置按住拖动，角色就往那个方向走；攻击全自动 |
| 角色 | 6 个二次元少女，各有起始武器和被动能力 |
| 画风 | 二次元 Q 版：淡紫粉嫩、细彩色线条、闪光点缀，精致但不刺眼 |
| 广告 | 只用玩家自愿看的激励视频，不打断战斗 |

---

## 2. 一局的流程

```
选角色 → 第 1 波 → 开宝箱 → 升级选属性 → 商店 → 第 2 波 → … → 第 10 波（Boss）→ 结算
```

- **战斗**：每波有倒计时。怪物会先在地上出现粉色预警标记，0.8 秒后才冒出来。撑到倒计时结束，这一波就过了。
- **每波开始时生命回满**。场上会长出 2 个星光花苞，第 2 波起有一定概率出现小偷猫。
- **波次结束**：场上剩下的星屑、糖果、宝箱自动飞到角色身上。先开这一波捡到的宝箱，再按升了几级连续选属性。
- **商店**：花星屑买武器和道具。

| 波次 | 时长 | 特别内容 |
|---|---|---|
| 1–4 | 20–30 秒 | 逐步出现新怪物；第 3 波起会刷出精英怪 |
| 5 | 打倒为止 | Boss：史莱姆国王 |
| 6–7 | 35–40 秒 | 怪物更多、更强 |
| 8 | 打倒为止 | Boss：暗影骑士 · 黑曜 |
| 9 | 45 秒 | 最后的准备 |
| 10 | 打倒为止 | 最终 Boss：史莱姆女王 |

Boss 波没有倒计时，必须打倒 Boss 才能过关。

## 3. 操作

- **移动**：手指按住屏幕任意位置拖动，出现一个虚拟摇杆，往哪拖角色就往哪走，松手停下。电脑上可以用 WASD 或方向键。
- **镜头**：场地比屏幕大得多（1500 × 2200），镜头跟着角色走，走到边上能看到岛的边缘和外面的云海。怪物在角色周围 200 到 650 的距离内刷新，地图大但战斗不稀。
- **攻击**：全自动。每把武器自己找射程内最近的敌人打；中立的花苞只有附近没有别的怪时才会被打。
- **受伤**：碰到怪物或被子弹打中会掉血，之后有 0.6 秒无敌。
- **暂停**：右上角暂停键（电脑上按 Esc 或 P），暂停时可以看全部属性、武器和道具。

## 5. 武器

最多带 6 把，绕着角色漂浮。买到和已有武器**同名同品质**的武器时，两把自动合成高一级（I → II → III → IV）。

| 武器 | 类型 | 攻击方式 |
|---|---|---|
| 星光杖 | 远程 | 向最近的敌人射出星光弹 |
| 月牙刃 | 近战 | 挥出月牙，砍中前方扇形内所有敌人 |
| 雷符 | 远程 | 落雷击中敌人后跳向附近 2 个敌人 |
| 清风扇 | 近战 | 扇出一圈风浪，伤害并击退周围敌人 |
| 泡泡枪 | 远程 | 一次射出 3 颗泡泡，近距离威力大 |
| 魔导书 | 远程 | 放出会追踪敌人的火球 |

品质倍率：伤害 ×1 / ×1.6 / ×2.5 / ×3.8，冷却 ×1 / ×0.9 / ×0.8 / ×0.7。

## 6. 道具

买了以后永久改变属性，可以重复买。首版约 15 个，例如：

| 道具 | 效果 |
|---|---|
| 星星糖 | 伤害 +8% |
| 魔力发卡 | 攻速 +10%，伤害 -3% |
| 软绵绵抱枕 | 生命上限 +5，移速 -3% |
| 猫铃铛 | 闪避 +6% |
| 小磁铁 | 拾取范围 +60 |
| 草莓蛋糕 | 生命上限 +8，生命回复 +1，移速 -5% |

很多道具有代价，逼玩家取舍，这是这类游戏耐玩的关键。

## 7. 升级与商店

- **星屑**：怪物死后掉落。捡到 1 个星屑 = 1 点经验 + 1 块钱。
- **升级**：经验满了就升级，在波次结束时统一选。每次 4 张属性卡选 1 张，卡片分普通 / 稀有 / 史诗 / 传说，幸运越高、波次越后越容易出好卡。
- **升级卡**会同时写出这项属性的当前值，方便判断要不要选。
- **商店**：每次 4 个商品（武器或道具），价格随波次上涨。
  - 刷新：花星屑换一批，每次刷新都会涨价。
  - 锁定：点商品右上角的锁，锁住的商品刷新时不会被换掉，下一波的商店里也还在。
  - 卖武器：点下面的武器栏选中一把，再点「卖掉」，拿回约 35% 的价钱。至少要留一把武器。
  - 买武器时如果武器栏满了、又不能合成，就买不了，会提示先卖掉一把。
  - 右上角「属性」可以随时看当前属性。
- **宝箱**：小偷猫和史莱姆国王会掉。波次结束时打开，随机得到一个道具，可以收下，也可以卖掉换约 50% 价钱的星屑。

### 7.1 掉落物

| 掉落物 | 来源 | 效果 |
|---|---|---|
| 星屑 | 所有怪物 | 1 块钱 + 1 点经验，靠近就会被吸过来 |
| 回血糖果 | 普通怪 3% 概率，花苞必掉 | 回 3 点生命；要走到很近才会吸过来，可以留着以后吃 |
| 宝箱 | 小偷猫、史莱姆国王 | 波次结束时开出一个道具 |

## 8. 怪物

都是萌系怪物，有大眼睛和表情，被打会挤眼睛、闪白。

| 怪物 | 出现 | 特点 |
|---|---|---|
| 果冻史莱姆 | 第 1 波 | 慢慢追你 |
| 星光花苞（中立） | 每波 2 个 | 不动、不伤人，打碎必掉回血糖果；血量每波 +5 |
| 小恶魔 | 第 2 波 | 跑得快、血少 |
| 小偷猫（特殊） | 第 2 波起随机出现 | 不伤人，一直逃跑，14 秒后溜走；打死掉宝箱和 8 个星屑 |
| 吐泡蘑菇 | 第 3 波 | 和你保持距离，吐泡泡子弹 |
| 冲锋兔 | 第 3 波 | 平时追你，每隔约 3 秒停下蓄力（发抖、冒「!」，地上出现冲锋路线），然后高速直线冲刺 |
| 盾骑士 | 第 4 波 | 血厚、走得慢、撞人疼 |
| 双子史莱姆 | 第 5 波 | 一半紫一半粉，打死分裂成两只又快又小的史莱姆 |
| 史莱姆国王（精英） | 第 5 波 | 体型巨大，血很厚，打死掉宝箱 |
| 史莱姆女王（Boss） | 第 10 波 | 向四周发射弹幕，不断召唤小史莱姆；跑出屏幕时边缘有箭头指示 |

怪物血量每波 +30%，伤害每 3 波 +1。怪物都用粉、紫、蓝、桃色，和绿色草地拉开对比。

### 8.1 精英怪

第 3 波起，普通怪物刷新时有一定概率变成精英（4%，之后每波 +1.2%）：

- 体型大 40%，血量 ×4，伤害 +2，被击退的距离减半。
- 外观：脚下暗紫色光环和红圈、往上飘的暗色雾气、发红光的竖瞳和怒眉。
- 打死掉 3 倍星屑，50% 掉糖果，35% 掉宝箱。

### 8.2 Boss

所有 Boss 的大招都会先预警：地上出现红色区域并逐渐填满，Boss 发抖、头上冒「!」，填满的瞬间招式落下。看清预警就能躲开。

- **登场**：画面定格约 2 秒，镜头移到 Boss 身上，上下出现黑边、四周泛红，弹出「⚠ BOSS 来袭 ⚠」横幅、Boss 名字和副标题，伴随吼叫和震屏。
- **阶段**：血量降到阶段线时 Boss 怒吼、清空场上子弹、换成更猛的招式。顶部 Boss 血条上有阶段刻度。
- **外观**：比普通怪更深的配色、红光眼睛、暗色光环。

| Boss | 血量 | 招式 |
|---|---|---|
| 史莱姆国王（第 5 波） | 1200 | **跳砸**：锁定你的位置画出红圈，跳起来砸下，落地放一圈弹幕；**召唤**小史莱姆。半血后一次连跳三下 |
| 暗影骑士 · 黑曜（第 8 波） | 2600 | **连续冲锋**：每次先画出一条红色冲锋路线，连冲 3 次（半血后 4 次）；**扇形弹幕**两轮；**旋转剑风**：脚下红圈填满后转圈斩击并放一圈弹幕 |
| 史莱姆女王（第 10 波） | 4200 | 三个阶段（60%、30%）：环形弹幕、扇形弹幕、旋转螺旋弹幕、召唤史莱姆和精英史莱姆；越往后出招越快，第三阶段双层环形弹幕、三臂螺旋 |

## 8.3 打击感

参考了同类游戏和打击感相关资料，见 [reference-notes.md](reference-notes.md)。

- **顿帧**：普通击杀停约 2 帧（间隔太近不会重复停），暴击、受伤、精英和 Boss 击杀、大招落地停得更久。
- **命中**：闪白、怪物抖动、按伤害大小击退、向受击方向溅出果冻水滴、白噪音加低频的「噗」声；暴击数字更大、带「!」、额外一声清脆音效。
- **击杀**：爆开冒烟、溅水滴、白色光圈，地上留下几秒后淡去的果冻渍。
- **开火**：远程武器有枪口闪光和轻微后坐，近战挥砍时镜头往攻击方向轻推。
- **震屏**：只给暴击（很轻）、精英、Boss、受伤和大招，避免每下都震导致麻木。
- **受伤**：屏幕四周闪红；血量低于 30% 时四周持续淡红呼吸。
- 调参面板里可以单独关掉震动、顿帧、受伤红边。

### 9.1 主动技能

每个角色有一个主动技能。右下角的技能按钮显示角色头像，外圈是能量环：

- 能量每秒 +4，每击杀一只怪 +3，满 100 可以释放；每波开始时有 40 点。

## 10. 美术方向：二次元 Q 版

- **整体**：淡紫、淡蓝、白色为主，金色点缀，到处有四角星闪光。参考你给的 AI 角色图。
- **线条**：细，用深靛紫或同色系的深色，不用纯黑。
- **场景**：漂浮在云海上的星光花园小岛，黄昏色调（草地和天空偏深、偏饱和，屏幕四周有暗角，让战斗更突出）。草地上零散分布小草、三叶草、小花、花瓣、石子和星尘闪光，中间有一圈半被草盖住的踏脚石和花坛，四周还有几片花圃和倒塌石柱的遗迹，通往各处的踏脚石小路；岛的边缘长着开花的灌木丛，底下露出泥土崖壁和垂下来的根须；外面是淡粉紫的天空和会慢慢飘的云，屏幕上还会飘花瓣。参考了土豆兄弟「一种底色 + 满地小细节、没有格子」的做法，详见 [reference-notes.md](reference-notes.md)。
- **角色**：战斗里用 Q 版小人（2 头身左右），顶部状态栏、暂停页用头像，结算界面用全身立绘。现在用的是从你的两张参考图里裁出来的图，要求和注意事项见 [art-spec.md](art-spec.md)。
- **怪物**：代码绘制，配色和线条跟角色统一。
- **界面**：左上角头像 + 血条 + 经验条 + 星屑 + 宝箱数 + 待升级提示，右上角波次倒计时和暂停键。
- **打击感**：命中闪白、怪物挤眼、伤害数字弹出、死亡时冒烟团和闪光、星屑被吸过来。
- **防止审美疲劳**：背景颜色克制，只有角色、怪物、子弹是鲜艳的；以后每 5 波换一个场景配色。

## 13. 首版原型范围

**已经做了：** 选角色、虚拟摇杆移动、镜头跟随的花园岛场景、6 种武器、8 种怪物 + 精英 + Boss、星屑 / 糖果 / 宝箱、升级选卡、商店（买、刷新、锁定、合成、卖武器）、暂停和属性页、10 波流程、失败和通关界面、复活和广告刷新占位、角色头像 / 小人 / 立绘接入。

另外已经做了：6 个角色的主动技能（技能按钮、能量、立绘切入）。

**以后做：** 武器流派加成、局外成长和难度等级、音乐、更多武器道具和场景、微信移植和真广告。
