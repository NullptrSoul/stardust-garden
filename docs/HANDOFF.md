## 二、接下来要做的（按顺序）

### 1. 注册数据库（5～10 分钟）

二选一（都免费）：

- **supabase.com**：用 GitHub 账号登录即可。国内速度没验证过。
- **腾讯云「云开发 CloudBase for Supabase 版」**：国内快，要实名；新人免费 6 个月，之后价格官网没写，到期前要看一下。

然后：

1. 新建一个项目（Project），记住你设的数据库密码（自己保管，不用给任何人）。
2. 打开项目的 **SQL Editor**，把 `docs/leaderboard.sql` 的内容整段粘进去，点 **Run**。没有红色报错就好。
3. 打开 **Settings → API**，抄下两样：
   - **Project URL**：像 `https://abcdefg.supabase.co`
   - **anon public key**（以 `eyJ` 开头的一长串）或 **publishable key**（以 `sb_publishable_` 开头）
4. **绝对不要用 service_role key / secret key**，那是管理员密钥，不能放进游戏。

### 2. 填进游戏配置

打开 `src/leaderboard.config.ts`，把空的地方填上，改成这样（换成你自己的）：

```ts
export const LEADERBOARD: { kind: 'supabase' | 'simple'; url: string; anonKey: string } = {
  kind: 'supabase',
  url: 'https://abcdefg.supabase.co',
  anonKey: 'eyJhbGciOi……（整串复制）',
};
```

腾讯云版本如果给的地址不是这种格式，或者后面测试连不上，等我回来看。

### 3. 在本地试一下

在项目文件夹里：

```bash
npm run dev
```

浏览器打开 `http://localhost:5173`：

1. 主界面点「排行」：下面那行小字如果是「每人只算最好的一局……」说明连上了；如果还是「线上排行榜还没开通」说明配置没生效。
2. 打一局无尽，至少打到第 2 波，死了以后点两次「回主界面」（或复活后再死），第一次会让你起名字。
3. 结束界面应该显示「总榜第 N 名 · 本周第 N 名」。显示「成绩没传上去」就是没连上。
4. 回主界面点「排行」，能看到自己的名字。
5. 到数据库控制台的 Table Editor 里，`scores` 表应该多了一行。

### 4. 发布到 GitHub

确认没问题后，在项目文件夹里依次运行：

```bash
npm test
```

```bash
git add -A
```

```bash
git commit -m "6 个角色新形象、无尽祝福和涨潮、排行榜、摇杆和防误触"
```

```bash
git push origin main
```

推上去后 GitHub 会自动测试并部署，大约 1～2 分钟。在仓库页面的 **Actions** 里能看到进度，绿色勾就是成功。然后刷新 https://nullptrsoul.github.io/stardust-garden/ 就是新版（手机上可能要清缓存或多刷新几次）。
